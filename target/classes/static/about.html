项目概述

GAMEVILA 是一个基于 Spring Boot 构建的现代化游戏平台，旨在为用户提供便捷的游戏浏览、搜索和管理体验。项目采用了当前主流的技术栈，实现了完整的用户认证系统、分级权限控制、智能搜索等功能。


核心目标：打造一个高性能、可扩展、安全的游戏平台，支持用户注册登录、VIP订阅管理、游戏分类浏览、智能搜索等核心功能。

核心功能

用户认证系统
完整的用户注册、登录、登出功能，采用 BCrypt 密码加密，确保用户数据安全。支持会话管理和自动登录状态检测。
VIP 权限管理
分级权限系统（免费/月度/季度/年度/终身VIP），根据用户等级展示不同内容，支持 VIP 订阅和权限验证。
智能搜索
基于 Trie 树和 N-Gram 算法的智能搜索引擎，支持自动补全、模糊匹配，提供快速准确的游戏搜索体验。
分布式会话
使用 Spring Session + Redis 实现分布式会话管理，支持服务器集群部署，会话数据持久化存储。
分类浏览
支持按游戏分类（冒险、RPG、竞速、解谜等）筛选浏览，动态加载游戏数据，提供流畅的用户体验。
浏览记录
本地存储用户浏览历史，最多保存 20 条记录，支持查看和清空浏览足迹，方便用户回顾感兴趣的游戏。

性能优化

  • Redis 缓存：会话数据和热点数据存储在 Redis 中，减少数据库查询压力
  • 搜索引擎：Trie 树和 N-Gram 索引预加载到内存，搜索时间复杂度 O(m)，m 为搜索词长度
  • 懒加载：JPA 关联查询采用懒加载策略，避免不必要的数据库查询
  • 连接池：使用 HikariCP 数据库连接池，优化数据库连接复用
  • 异步处理：前端采用异步 fetch API，非阻塞式数据加载，提升用户体验

部署与运行

环境要求：

  • JDK 17 或更高版本
  • MySQL 8.0 数据库
  • Redis 7.x 缓存服务
  • Maven 3.6+ 构建工具

启动步骤：

# 1. 启动 MySQL 和 Redis 服务 net start MySQL80 net start Redis # 2. 配置数据库连接（application.properties） spring.datasource.url=jdbc:mysql://localhost:3306/Game spring.data.redis.host=localhost # 3. 编译并运行项目 mvn clean install mvn spring-boot:run # 4. 访问应用 http://localhost:8080/home.html
